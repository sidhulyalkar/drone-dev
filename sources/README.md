# Source manifests

`reference_sources.v0.3.json` is a machine-readable ledger of the real-source reference study, generated from `core/reference_lab.mjs`. It includes manufacturer source URLs and access dates. Sources are research evidence, not supplier or inventory guarantees.

AeroForge does not bundle third-party CAD files. Source Two CAD is licensed GPL-3.0 upstream and is referenced by URL only. The v0.2 illustrative part catalog is retained distinctly as hypothetical component classes.
